## ขั้นที่ 1 — สร้าง Google Sheets + วางสคริปต์ (ประมาณ 10 นาที)

1. เข้า [sheets.new](https://sheets.new) ด้วยบัญชี **houseofhapinessbangkok@gmail.com**
   (บัญชีที่รับอีเมลจาก Booking.com) แล้วตั้งชื่อไฟล์ เช่น `HOH Bookings`
   > สำคัญ: อีเมลยืนยันการจองจาก Booking.com ต้องเข้ากล่องนี้ — ตั้งใน Extranet
   > (เมนู Account → Contacts) หรือตั้ง Outlook เดิมให้ส่งต่ออัตโนมัติมาที่อีเมลนี้
2. เมนู **Extensions → Apps Script** จะเปิดหน้าเขียนสคริปต์
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ **`backoffice/apps-script.gs`** ในรีโปนี้
4. บรรทัดบนสุด แก้ `var TOKEN = "เปลี่ยนรหัสลับตรงนี้";`
   → ตั้งรหัสลับยาว ๆ ของคุณเอง เช่น `hoh-2569-xK9mPq` (จดไว้ ใช้ในขั้นที่ 3)
5. กด 💾 บันทึก

### เปิดใช้ Web App (ให้เว็บไซต์คุยกับชีตได้)

6. กดปุ่ม **Deploy → New deployment**
7. กดไอคอนเฟือง เลือกประเภท **Web app** แล้วตั้งค่า:
   - Execute as: **Me**
   - Who has access: **Anyone**  ← จำเป็น (ความปลอดภัยอยู่ที่ TOKEN ไม่ใช่หน้านี้)
8. กด **Deploy** → อนุญาตสิทธิ์ที่ระบบถาม → **คัดลอก URL** ที่ลงท้ายด้วย `/exec` (จดไว้)

### เปิดการสแกนอีเมลอัตโนมัติ

9. ในหน้า Apps Script เลือกฟังก์ชัน **`setupTriggers`** จากเมนูด้านบน แล้วกด **Run**
   (อนุญาตสิทธิ์ Gmail ที่ระบบถาม — สคริปต์อ่านเฉพาะอีเมลจาก booking.com เท่านั้น)
10. ทดสอบทันทีได้โดยเลือกฟังก์ชัน **`testScanNow`** แล้วกด Run → เปิดชีตดู
    ถ้ามีอีเมลจองจาก Booking.com ใน 7 วันที่ผ่านมา จะเห็นแถวข้อมูลปรากฏ

> อีเมลที่อ่านแล้วจะถูกติดป้าย `HOH-บันทึกแล้ว` ใน Gmail จะได้ไม่บันทึกซ้ำ
> อีเมลที่อ่านไม่สำเร็จจะถูกบันทึกเป็นแถว "ตรวจสอบเอง" — ไม่มีการจองหายเงียบ ๆ

|---|---|

| `STAFF_PASSWORD` | *(ไม่บังคับ)* รหัสสำหรับพนักงาน — เข้าหน้า /admin ได้ เห็นผังห้อง/กดงานได้ครบ แต่**มองไม่เห็นตัวเลขเงิน** (รายได้/ยอดจอง ถูกตัดตั้งแต่เซิร์ฟเวอร์) และแก้ยอดเงินไม่ได้ |

### (สำคัญมาก) เติมวันที่เข้าพักด้วยไฟล์ CSV จาก Booking.com

อีเมลของ Booking.com ยุคใหม่**ไม่บอกวันที่เข้าพักครบถ้วน** และ Booking.com
**เลิกแจกลิงก์ปฏิทิน iCal แล้ว** (ให้ไปใช้แอป Pulse แทน) — วิธีเติมวันที่จริง
ตอนนี้คือดาวน์โหลดไฟล์รายการจองจาก Extranet มานำเข้าในหลังบ้าน

ทำสัปดาห์ละครั้ง (ผ่านคอมพิวเตอร์ ไม่ใช่แอป Pulse):
1. เข้า **Extranet** (admin.booking.com) → เมนู **การจอง (Reservations)**
2. เลือกช่วงวันที่ให้ครอบคลุมการจองที่ยังไม่เข้าพัก → กด **ดาวน์โหลด (Download)** ได้ไฟล์ `.csv`
3. เปิดหลังบ้าน `/admin` แท็บการจอง → กดปุ่ม **⬆ นำเข้าไฟล์ Booking** → เลือกไฟล์ที่ดาวน์โหลด
4. ระบบจับคู่ด้วยหมายเลขการจอง แล้วเติมวันที่เช็คอิน/เช็คเอาต์ ชื่อผู้เข้าพัก ยอดเงิน
   และสถานะยกเลิกให้อัตโนมัติ (ไม่ทับข้อมูลที่กรอกไว้แล้ว)

| Name | Value |
|---|---|
| `SAFETY_BUFFER` | *(ไม่บังคับ)* จำนวนห้องที่กันไว้ไม่โชว์ว่าว่างบนหน้าเว็บ — ค่าเริ่มต้น `1` (ใส่ `0` ถ้าอยากโชว์ทุกห้อง) |

> หมายเหตุ: ตัวแปร `BOOKING_ICAL_URLS` แบบเดิมยังใช้ได้ถ้ามีลิงก์ iCal เก่าอยู่
> แต่บัญชีใหม่จะไม่มีเมนู Sync calendars ให้แล้ว

- เปิด **https://houseofhappinessbangkok.com/admin** → ใส่รหัส `ADMIN_PASSWORD`
  (พนักงานใช้ `STAFF_PASSWORD` — หน้าจอเดียวกันแต่ไม่มีส่วนรายได้ มุมซ้ายบนจะขึ้น "โหมดพนักงาน")
- **ผังห้อง**: สีบอกสถานะ (ว่าง / มีผู้พัก / เช็คอินวันนี้ / รอทำความสะอาด)
  แตะห้องเพื่อ **เช็คอิน** (จากการจองหรือ walk-in) / **เช็คเอาต์** / **ย้ายห้อง** / **ทำความสะอาดเสร็จ**
  — ทุกปุ่มบันทึกกลับลงชีตอัตโนมัติ
- รายชื่อห้องอยู่ในชีตแท็บ **Rooms** (สร้างให้อัตโนมัติตามผังจริง 701-718 + งิ้ว2-3 —
  เปลี่ยนชื่อห้อง/เพิ่ม/ลบ/สลับลำดับได้เองในชีต ทุกหน้าจอเรียงตามชีต)
- **สถิติเดือนนี้**: รายได้ตามยอดจอง · คืนที่ขายได้ · อัตราเข้าพัก
- ปฏิทินรายเดือน (แตะวันดูรายชื่อ) + ตารางการจองค้นหาได้
- อยากแก้ข้อมูลละเอียด ๆ → แก้ในชีตได้เลย หน้า /admin อ่านจากชีตสด ๆ ทุกครั้งที่รีเฟรช
- คำขอจองตรงจากหน้าเว็บจะเข้าชีตเป็นสถานะ "รอยืนยัน" อัตโนมัติ

### ติดตั้งเป็นแอปบนมือถือ (PWA)

- **Android (Chrome)**: เปิด /admin → เมนู ⋮ → **เพิ่มไปยังหน้าจอหลัก / ติดตั้งแอป**

### คอลัมน์ในชีต

## คำถามที่พบบ่อย

**ถ้า Booking.com เปลี่ยนรูปแบบอีเมลจนอ่านไม่ได้?**
แถวจะขึ้นเป็น "ตรวจสอบเอง" พร้อมหัวข้ออีเมล — เปิดอีเมลแล้วคีย์แก้ในชีตได้เลย
ระบบออกแบบให้ *ไม่มีการจองหายเงียบ ๆ* ถ้าเป็นอีเมลเก่าที่อ่านได้บางส่วน ให้รัน
`repairIncompleteBookingsFromEmails` เพื่อเติมเฉพาะช่องว่างก่อน แล้วเทียบรายการที่ยังขาดกับ Pulse/CSV

**ปลอดภัยแค่ไหน?**
หน้า /admin ต้องใส่รหัสผ่านทุกครั้ง (จำไว้เฉพาะแท็บนั้น), ชีตคุยกับเว็บผ่านรหัสลับ TOKEN,
Google เห็นข้อมูลเท่าที่อยู่ในชีตของบัญชีคุณเอง และหน้า /admin ถูกตั้ง noindex ไม่ให้ติดค้นหา

**ในอนาคตถ้าอยากได้มากกว่านี้ (กันจองซ้อน, ซิงก์ราคา, หลายแพลตฟอร์ม)?**
ค่อยย้ายไป Channel Manager เช่น Beds24 (~$25/เดือน) — ข้อมูลในชีตนี้ export ไปได้
