# แผนทำคู่มือ Grab และ Bolt สำหรับแขก — House of Happiness

สถานะ: ร่างแผน รอเจ้าของเลือกรูปแบบและตอบข้อเท็จจริงหน้างาน (หมวด 7) ก่อนลงมือ
เขียนเมื่อ 24 ก.ย. 2569

---

## 1. ทำไปเพื่ออะไร และใครใช้

- แขก ~92% เป็นชาวต่างชาติ ส่วนใหญ่ไม่เคยใช้แอปเรียกรถในไทย ปัญหาที่เจอซ้ำ ๆ คือ
  ปักหมุดผิด คนขับหาซอยไม่เจอ โทรมาแล้วคุยกันไม่รู้เรื่อง จ่ายเงินสดไม่มีทอน
  และไม่รู้ว่าที่สนามบินต้องไปรอตรงไหน
- เจ้าหน้าที่อยู่ถึง 18:00 หลังจากนั้นแขกต้องช่วยตัวเอง คู่มือนี้จึงต้องใช้ได้ **ตอนไม่มีคนตอบ**
- งานของคู่มือในประโยคเดียว: *ให้แขกที่ไม่เคยใช้ Grab/Bolt มาก่อน เรียกรถถึงหน้าบ้านและออกจากบ้านได้เองภายใน 5 นาที โดยไม่ต้องทักเรา*
- ขอบเขต: **รถยนต์** (GrabCar / Bolt) เป็นหลัก มอเตอร์ไซค์ (GrabBike / Bolt Moto) และ GrabFood พูดถึงสั้น ๆ พอ
- **ไม่ทำ**: เปรียบเทียบราคาสองแอปแบบตัวเลขตาย เพราะราคาขึ้นลงตามเวลา จะเขียนเป็นช่วงและวิธีเช็กเอง

## 2. เนื้อหาหลัก 3 สถานการณ์ (โครงคู่มือ)

คู่มือจะเรียงตาม "ช่วงเวลาที่แขกต้องใช้" ไม่ใช่เรียงตามแอป เพราะแขกมาเปิดตอนมีปัญหา ไม่ได้มาอ่านเล่น

### ส่วน A — เตรียมก่อนถึงไทย (อ่านตอนอยู่บ้าน 3 นาที)
1. โหลดแอปทั้งสองไว้ตั้งแต่ก่อนบิน ลิงก์ App Store / Play Store
2. สมัครด้วยเบอร์ประเทศตัวเองได้ (ต้องรับ SMS ได้ตอนอยู่ไทย → แนะนำเปิด roaming หรือใช้ eSIM ไทย)
3. ผูกบัตรเครดิตไว้ก่อน จะได้ไม่ต้องหาเงินสดตอนลงจากเครื่อง
4. **บันทึกที่พักไว้ในแอป** (Saved places / Home) ด้วยหมุดที่เราให้ ข้อนี้คือหัวใจของทั้งคู่มือ
5. เก็บภาพ "การ์ดที่อยู่ภาษาไทย" ไว้ในมือถือ (ดูหมวด 4)

### ส่วน B — จากสนามบินมาบ้าน (ใช้จริงตอนลงเครื่อง)
- **สุวรรณภูมิ**: จุดรับ Grab/Bolt อยู่ที่ไหน ต้องเดินจากประตูออกไปทางไหน ป้ายเขียนว่าอะไร มีจุดรับคนละที่กับแท็กซี่มิเตอร์ (ต้องยืนยันตำแหน่งจริง ณ วันเขียน — หมวด 7)
- **ดอนเมือง**: เช่นเดียวกัน แยกอาคาร 1 (ระหว่างประเทศ) กับอาคาร 2 (ในประเทศ)
- ราคาเป็นช่วง ใช้ตัวเลขที่เว็บใช้อยู่แล้ว: BKK 45–60 นาที ~350–450 บาท · DMK 40–60 นาที ~250–350 บาท (รวมทางด่วน) พร้อมหมายเหตุว่าแอปจะบอกราคาสุทธิก่อนกดยืนยัน
- ค่าทางด่วน: Grab บางประเภทรวมแล้ว บางประเภทคนขับเก็บเพิ่ม ให้แขกอ่านบรรทัด "Tolls" ในแอป
- ระหว่างทาง: คนขับอาจโทรมา ถ้าคุยไม่ได้ให้กดข้อความ template ในแอป (Grab มีข้อความสำเร็จรูปแปลอัตโนมัติ) หรือส่งการ์ดที่อยู่ภาษาไทย
- นาทีสุดท้าย: ซอยท่าดินแดง 16 — คนขับต้องเลี้ยวจากถนนท่าดินแดงเข้าซอย จอดตรงไหน ต้องบอกอะไร (ข้อเท็จจริงหน้างาน — หมวด 7)
- ถึงหลัง 18:00 → โยงไปขั้นตอน self check-in

### ส่วน C — ใช้ระหว่างพัก และวันกลับ
- เรียกรถ **ออกจากบ้าน**: ปักหมุดตรงไหนให้คนขับหาเจอง่าย (หน้าบ้าน หรือปากซอย) ควรเดินไปรอปากซอยไหม ตอนไหน
- เวลาไหนควรใช้แอป เวลาไหนควรใช้เรือ/รถไฟฟ้า (โยงไป getting-around-bangkok.html ไม่เขียนซ้ำ)
- ราคาอ้างอิงจากบ้านไปจุดที่แขกไปบ่อย ใช้ตัวเลขที่มีอยู่แล้วบนเว็บ: ข้ามสะพานพระปกเกล้าไปเยาวราช/วัดโพธิ์ ~10 นาที ~70–100 บาท · ไอคอนสยาม · สยาม/สุขุมวิท (ต้องเช็กจริง)
- ชั่วโมงเร่งด่วน 07:00–09:00 และ 17:00–19:30 ราคาพุ่ง (surge) และเวลารอนาน วิธีดู "รอ 2 นาทีแล้วรีเฟรช" หรือสลับแอป
- ฝนตก: ราคาขึ้นทั้งสองแอป รถหายาก ให้เผื่อเวลา
- **มอเตอร์ไซค์**: เหมาะระยะสั้น 1 คน ไม่มีกระเป๋าใหญ่ ต้องใส่หมวก แอปให้ราคาก่อน ไม่ต้องต่อ
- **GrabFood** สั้น ๆ: สั่งได้ถึงหน้าบ้าน ให้ใส่หมุดเดียวกัน แขกรับเองที่หน้าบ้าน (ทีมงานไม่รับของแทนหลัง 18:00 — ต้องยืนยันนโยบาย)
- วันกลับไปสนามบิน: จองล่วงหน้าได้ไหม (Grab มี "Advance booking" ในบางพื้นที่ — ต้องเช็กว่าใช้ได้กับที่พักเรา) เผื่อเวลาเท่าไร ควรออกจากบ้านกี่โมงสำหรับไฟลต์เช้า/เย็น

### ส่วน D — Grab กับ Bolt ต่างกันยังไง (ตารางเดียว ไม่ยาว)
| | Grab | Bolt |
|---|---|---|
| หาคนขับได้ง่าย | มากกว่า โดยเฉพาะสนามบินและดึก | น้อยกว่าเล็กน้อยในฝั่งธนฯ (ต้องเช็กจริง) |
| ราคา | มักสูงกว่า | มักถูกกว่า 10–30% แต่ surge แรงกว่าตอนฝน (ต้องเช็ก) |
| จ่ายเงิน | บัตร / เงินสด / GrabPay | บัตร / เงินสด |
| แชตแปลภาษา | มี | มี |
| จุดรับที่สนามบิน | มีจุดเฉพาะ | ใช้จุดเดียวกันหรือไม่ (ต้องเช็ก) |
| บริการอื่น | Food, Mart, Express | รถอย่างเดียว (และ Moto) |

คำแนะนำสั้น ๆ ของเรา: เปิดทั้งสองแอป เทียบราคาแล้วกด ถ้ารอเกิน 5 นาที สลับ

### ส่วน E — แก้ปัญหาที่เจอบ่อย (FAQ 8–10 ข้อ)
1. คนขับโทรมา แต่ฉันพูดไทยไม่ได้ → ไม่ต้องรับสาย ส่งข้อความในแอป / ส่งการ์ดที่อยู่
2. คนขับปักหมุดไม่ตรง หาซอยไม่เจอ → รูปประกอบ + landmark ปากซอย
3. คนขับยกเลิก / ไม่ขยับ → รอ 3 นาที ยกเลิกเอง (ฟรีถ้ายังไม่ถึงเวลา) แล้วเรียกใหม่หรือสลับแอป
4. โดนขอเงินเพิ่มจากราคาในแอป → ไม่ต้องจ่าย ราคาในแอปคือราคาจริง ยกเว้นทางด่วนถ้าแอปบอกว่าไม่รวม
5. ราคาแพงกว่าที่คิดมาก → surge ลองรอหรือสลับแอป หรือใช้แท็กซี่มิเตอร์ (ยืนยันกดมิเตอร์)
6. จ่ายเงินสด ไม่มีแบงก์ย่อย → คนขับส่วนใหญ่ทอน 500 ได้ 1,000 อาจไม่ได้ ควรแตกแบงก์ที่สนามบิน
7. ลืมของบนรถ → ปุ่ม Help ในแอป ติดต่อคนขับผ่านแอปได้ 24 ชม. หลังจบทริป (ต้องเช็กเงื่อนไข)
8. ต้องทิปไหม → ไม่บังคับ ให้ผ่านแอปได้
9. เด็กเล็กต้องมีคาร์ซีทไหม → ไม่บังคับตามกฎหมายไทยในรถรับจ้าง แต่ไม่มีให้ (ต้องเช็กข้อกฎหมาย ณ ปี 2569)
10. ตี 2 มีรถไหม → มี ทั้งสองแอป แต่รอนานขึ้นและราคาสูงขึ้น

## 3. รูปแบบที่ควรทำ — เสนอทำ 3 ชิ้นจากต้นฉบับเดียว

| ชิ้น | ใครใช้ตอนไหน | ทำเป็นอะไร |
|---|---|---|
| **1. หน้าเว็บ** `ride-hailing-guide.html` (+ `/en/`) | อ่านก่อนบิน · Google หาเจอ · ส่งลิงก์ให้แขกทาง LINE ตอนยืนยันจอง | ใช้เทมเพลต `.ld-*` เดียวกับ airport-guide มี FAQ schema, ปุ่มคัดลอกที่อยู่, ปุ่มเปิดหมุด |
| **2. การ์ดที่อยู่สำหรับคนขับ** (ภาพ 1 ใบ) | แขกเซฟลงมือถือ โชว์คนขับ / ส่งในแชตแอป | ภาพ PNG ไทย+อังกฤษ 1080×1350 ที่อยู่ไทยตัวใหญ่ + แผนที่ซอย + QR เปิดหมุด + เบอร์เรา ทำจาก HTML แล้ว export |
| **3. แผ่นในห้อง / ข้อความ LINE** | ตอนอยู่ในห้องหรือหลังทีมงานกลับ | A5 1 หน้าใส่แฟ้มในห้อง (QR ไปหน้าเว็บ + การ์ดที่อยู่ + 5 ข้อสั้น ๆ) และข้อความสำเร็จรูป 1 ก้อนสำหรับส่งใน LINE/WhatsApp |

หลักการ: เขียนเนื้อหาครั้งเดียวในหน้าเว็บ แล้วชิ้น 2–3 ดึงจากหน้านั้น จะได้แก้ที่เดียว

## 4. การ์ดที่อยู่สำหรับคนขับ — สเปก

- ด้านบน (ไทย ตัวใหญ่ที่สุด): เฮาส์ ออฟ แฮปปิเนส 558/1 ถนนท่าดินแดง ซอย 16 แขวงคลองสาน เขตคลองสาน กรุงเทพฯ 10600
- บรรทัดสำหรับคนขับ (ไทย): "เข้าซอยท่าดินแดง 16 … [จุดสังเกต] … อาคารอยู่ [ซ้าย/ขวา] [ระยะ] เมตร" ← ต้องได้ข้อมูลจากเจ้าของ
- อังกฤษเล็กกว่า: House of Happiness, 558/1 Tha Din Daeng Soi 16, Khlong San
- QR code → หมุด Google Maps ตัวเดียวกับที่ใช้ในเว็บ (อย่าใช้หลายหมุด)
- เบอร์โทรที่พัก + LINE ID พร้อมประโยคไทย "โทรหาที่พักได้ที่เบอร์นี้ถ้าหาไม่เจอ"
- แผนที่ซอยแบบวาดง่าย: ถนนท่าดินแดง → ปากซอย 16 → จุดจอด (ทำจากรูปถ่ายจริง + ลูกศร ไม่ใช่แผนที่ Google ถ่ายจอ)
- ไฟล์: PNG และ PDF วางไว้ที่ `images/driver-card-th-en.png` และแนบใน LINE Rich Menu ได้

## 7. คำถามที่ต้องให้เจ้าของตอบก่อน (ผมเดาไม่ได้ เป็นข้อเท็จจริงหน้างาน)

1. รถยนต์เข้าซอยท่าดินแดง 16 ถึงหน้าบ้านได้ไหม หรือต้องลงปากซอยแล้วเดิน ระยะเดินกี่เมตร
2. ซอยเป็นทางเดียว/สองทาง มีจุดกลับรถไหม ตอนออกคนขับต้องขับต่อไปทางไหน
3. ประโยคบอกทางคนขับที่ทีมงานใช้พูดจริงทางโทรศัพท์ทุกวันนี้ คืออะไร (ขอประโยคที่ใช้อยู่ ไม่ต้องแต่งใหม่) จุดสังเกตปากซอยคืออะไร (ร้าน วัด เซเว่น ป้าย)
4. หมุด Google Maps ที่ถูกต้องคือหมุดไหน (ลิงก์) เคยมีแขกหลงเพราะหมุดผิดหรือไม่ ผิดไปตรงไหน
5. เบอร์โทรที่ให้คนขับโทรได้คือเบอร์ไหน หลัง 18:00 มีใครรับไหม ถ้าไม่มี ให้เขียนว่าใช้แชตในแอปแทน
6. เคยมีแขกบ่นเรื่อง Grab/Bolt แบบไหนบ้าง (จากรีวิวหรือแชต) จะเอามาเป็น FAQ ข้อแรก ๆ
7. GrabFood / พัสดุ: ทีมงานรับแทนแขกได้ไหม ช่วงเวลาไหน
8. อยากให้แนะนำแอปไหนเป็นหลัก หรือให้กลางทั้งคู่ (ผมเสนอกลาง เพราะเราไม่ได้รับอะไรจากทั้งสองแอป และการมีสองแอปช่วยแขกจริง)
9. มีแท็กซี่/คนขับประจำที่ที่พักใช้อยู่ไหม ถ้ามี จะใส่เป็นตัวเลือกที่ 3 "ให้เราจองรถให้" ในหน้านี้ด้วยหรือไม่ และคิดราคายังไง
10. ทำเป็น A5 ใส่ในห้องด้วยไหม หรือเอาแค่หน้าเว็บ + การ์ดคนขับ

## 8. สิ่งที่ผมจะไม่ทำ และเหตุผล

- ไม่ใส่ตัวเลขราคาที่ผมเช็กไม่ได้ ณ วันเขียน จะเขียนเป็นช่วงหรือบอกให้ดูในแอป
- ไม่ใส่โปรโมโค้ดของแอป เพราะเปลี่ยนบ่อยและหมดอายุแล้วทำให้แขกหมดความเชื่อถือทั้งหน้า
- ไม่เขียนว่า "Bolt ถูกกว่าเสมอ" หรือ "Grab ปลอดภัยกว่า" ถ้าไม่มีหลักฐาน
- ไม่ทำภาพจอแอปปลอม ต้องเป็นภาพถ่ายจอจริงจากมือถือของเรา หรือไม่มีภาพ
- ไม่แก้หน้า airport-guide / getting-around ให้ยาวขึ้น แค่ใส่ลิงก์มาหน้าใหม่ 1 บรรทัด

## 9. วัดผลหลังปล่อย (เพื่อรู้ว่าคุ้มไหม)

- จำนวนแชต LINE ประเภท "คนขับหาไม่เจอ / รอตรงไหน" ต่อเดือน ก่อน–หลัง (นับจากประวัติแชท)
- Vercel Analytics: ยอดเข้าหน้านี้ และแขกกดปุ่ม "คัดลอกที่อยู่" กี่ครั้ง
- ถามแขก 5 คนแรกที่ใช้ว่าขาดอะไร แล้วปรับ 1 รอบ
