# E2E test หน้าจอง (Playwright)

ทดสอบ flow จองด้วยเบราว์เซอร์จริง โดยจำลอง /api/* ทั้งหมด — **ไม่สร้างการจองจริง ไม่แตะชีตจริง**

```bash
cd tests/e2e
npm install
npx playwright install chromium   # ครั้งแรกครั้งเดียว (ถ้าเครื่องยังไม่มีเบราว์เซอร์)
node booking.e2e.js
```

ตรวจ 7 อย่าง: ขั้นต่ำ 2 คืน (หน้าจอง+หน้าแรก+พรีฟิลจากลิงก์), ชิป 2/3/5,
ลิงก์ LINE ต้องเป็น @ ดิบ (บั๊ก %40 เคยทำ LINE เปิดไม่ได้), การยิง /api/book และแสดงเลขที่จอง

## analytics.e2e.js
ตรวจตัวนับเหตุการณ์ Vercel Analytics: ยิงถูกชื่อ/ช่องทาง, ปุ่มที่ยังกดไม่ได้ต้องไม่นับ,
กล่อง LINE บนคอมนับแยกจากลิงก์ปกติ, และ **ข้อมูลส่วนตัวต้องไม่หลุดไปกับ event**
(ชื่อ เบอร์โทร วันเข้าพัก หมายเหตุที่แขกพิมพ์ รายการอาหาร) รวมถึงต้องไม่พังเมื่อ analytics ปิดอยู่

    node tests/e2e/analytics.e2e.js
